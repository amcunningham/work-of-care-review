# The Work of Care: review protocol and first-pass findings

A working review by Anne Marie Cunningham of how health services divide the work of recognising need (selection, triage, assessment, eligibility decisions) from the work of responding to it, and what that division costs.

**Status: provisional.** One reviewer; web searches and PubMed only; many sources read at abstract level. The classification of findings as established, inferred or hypothesis is a proposal to be challenged.

## Contents

- `lay-summary.md`: a plain-language summary with a source for each point.
- `review.md`: the review document (protocol, findings, search log, source checks). Start with the short answer.
- `data/included_records.csv`: PubMed records provisionally included, with full-text availability and notes.
- `searches/`: exported PubMed result sets with the search strings used.

## How this is maintained

The working copy is edited elsewhere and exported to `review.md`. The commit history shows what changed and when. The review was drafted with the assistance of Claude (Anthropic).
